# 2. Drei-Stufen-Evolution

> Biomimetische und selbstwachsende Strukturen: Eine Vision für adaptive Habitate auf dem Mars

**DOI:** [10.5281/zenodo.16540444](https://doi.org/10.5281/zenodo.16540444)

---

## Überblick

Dieses Kapitel präsentiert eine dreistufige konzeptionelle Evolution des
Martialen Habitatbaus — von traditionellen Ingenieurprinzipien über biomimetische
Leichtbaumaterialien bis hin zu autonomen, selbstwachsenden silikonbasierten Strukturen.
Aufbauend auf dem Mars Gummi-Glashaus Projekt skizziert diese Arbeit einen
skalierbaren, nachhaltigen Weg für künftige Mars-Habitate.
